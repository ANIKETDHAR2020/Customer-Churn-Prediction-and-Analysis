# Customer-Churn-Prediction-and-Analysis

An end-to-end Customer Churn Analysis project built using **Python, SQL (SQLite), Pandas, Matplotlib, and Seaborn** to analyze customer behavior, identify churn patterns, calculate business KPIs, and generate actionable business insights.

> **Note:** This project was completed as a guided learning project by following the YouTube tutorial **"Complete Data Analytics Portfolio Project | Learn How Data Analyst Work (Python + SQL)"**. The implementation, analysis, and documentation were completed as part of my learning journey.

---

##  Project Objectives

- Analyze customer churn trends.
- Build and query a relational SQLite database.
- Clean and transform customer data.
- Perform exploratory data analysis (EDA).
- Calculate business KPIs.
- Generate actionable business insights and recommendations.

##  Project Workflow

- Imported and cleaned raw customer data.

##  Key Business KPIs

- Churn Rate
- Retention Rate
- ARPU (Average Revenue Per User)
- Average Customer Tenure
- Revenue at Risk
- Escalation Rate
- Average Complaints per Customer

---

##  Visualizations

The project includes:

- Customer churn by subscription plan
- Monthly churn trend
- Correlation heatmap
- Pivot table analysis
- Database schema and business metrics

---

##  Key Insights

- Overall churn rate: **28.6%**
- Retention rate: **71.4%**
- Basic subscription plan has the highest churn.
- Karnataka recorded the highest customer churn.
- Monthly subscriptions experience significantly higher churn than annual subscriptions.
- Approximately **18%** of revenue is at risk due to customer churn.
